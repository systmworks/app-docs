# Aussie Unit Price

A free Chrome extension for Aussie online shops that sell the same thing in different pack sizes
but don't tell you which one is actually cheaper. It adds the price per item (and per litre or per
kilo when the size is known) to every product, highlights the best value, and lets you sort the
page by it. It only reads the page you are viewing, and sends nothing anywhere.

- [What's new](whats-new.md): new features and fixes, release by release
