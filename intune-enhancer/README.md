# Intune Enhancer

A free Chrome and Edge extension that adds missing information and time-saving tools to the
Microsoft Intune admin center. Read-only: it never changes your tenant, and it only talks to
Microsoft Graph.

- [Install / Download](download/README.md): store links, manual install, and the published package with its checksum
- [What's new](whats-new.md): new features and fixes, release by release
- [Screenshots](https://github.com/systmworks/app-docs/blob/main/intune-enhancer/screenshots/README.md): every feature, on a fictional tenant
