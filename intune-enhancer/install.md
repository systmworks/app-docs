# Install Intune Enhancer

Intune Enhancer adds the details Intune leaves out (primary users, group sizes, setting checks and more) to the
Intune admin center. It is read-only and uses your own Intune sign-in, so there is no app registration to set up.

## Choose your browser

| Microsoft Edge | Google Chrome |
|---|---|
| [Install from Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/intune-enhancer/hcmhldmcpgieiaeobdbppcgfckahdeci) | [Install from the Chrome Web Store](https://chromewebstore.google.com/detail/intune-enhancer/geifmacoimaenjdednhfiegamkjkgjjm) |

## After you install

1. A tab opens on the extension's **Settings** page. Read the short disclosure and choose **Agree and turn on**.
   Nothing works until you agree.
2. Open [intune.microsoft.com](https://intune.microsoft.com/) and sign in as usual. The extra details appear in
   Intune's own pages, and the extension's **workspace** (click its toolbar icon) holds the larger tools.
3. Want to look around first? Change the end of the workspace tab's address from `workspace.html#settings` to
   `workspace.html?sample=1` and press Enter. Every tool then runs on a fictional tenant, and nothing is read from
   Microsoft.

## Manual install (advanced)

Use this only if you have been given a ZIP file instead of a store link. A store install updates itself
automatically when a new version is approved; a manual install does not, so to update it you load the new ZIP the
same way (or remove it and install from the store instead).

1. Extract the ZIP into a folder you will keep (the browser reads the extension from there).
2. Open `edge://extensions` in Edge, or `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (a switch in a corner of the page).
4. Choose **Load unpacked** and select the folder you extracted.
